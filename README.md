# Scheda Ale

Tracker della scheda di allenamento: carichi di ogni seduta, progressi con grafici, segnale "aumenta / tieni" e timer di recupero.
App web installabile (PWA, Progressive Web App): funziona offline e i dati restano sul telefono.

Installazione su iPhone: apri il link con Safari > Condividi > Aggiungi alla schermata Home.
